# Notice border geometry

Equal corner radii should survive wide windows, wrapped text, and display scaling.

> [!NOTE]
> This is helpful, neutral information.

> [!TIP]
> Resize the window: the corners should remain circular, not stretch with the notice.

> [!IMPORTANT]
> Preserve source order and accessible semantics in every visual transformation.
>
> This taller notice exercises the same border geometry as the short notices around it. The thicker left edge should flow into both rounded corners without a detached rail or a protruding cap.

> [!WARNING]
> Very tall screen columns can force readers to scroll backward to continue.

> [!CAUTION]
> Never use a masonry layout for ordered steps: it makes sequence ambiguous.
