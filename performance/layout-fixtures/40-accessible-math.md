# Structured equations

Inline context stays in its original paragraph: $a^2+b^2=c^2$. Each display equation below retains its exact editable LaTeX source.

## Fraction

```math
\frac{37}{41}
```

## Indexed radical and scripts

```math
\sqrt[3]{x_2^4}
```

## Matrix

```math
\begin{pmatrix}17&23\\31&43\end{pmatrix}
```

## Operator limits

```math
\sum_{i=1}^{9}i^2
```

## Invalid source remains available

```math
\notARealCommand{x}
```

The final paragraph remains editable after every equation.
