# Markdown document language

The document language distinguishes authored relationships from their automatic
visual arrangements.

## Language

**Definition list**:
A source-ordered collection of terms and their associated descriptions. It is
not an unordered feature list or a comparison table.

**Definition term**:
The authored label being explained, including its inline formatting. Its visual
weight does not make it a section heading or add it to the document outline.

**Definition description**:
One explanation attached to the preceding term. It may contain several
paragraphs, lists, code examples, or other supporting document content.

**Aligned definition rows**:
A presentation with terms on a shared leading rail and descriptions alongside
them. The same relationships remain when space requires stacked groups.

**Text flow**:
A sequence of prose blocks within one authored context, such as a description
or a quotation. Different definition roles, list items and table cells are
distinct flows even when they appear next to each other.

**Semantic boundary**:
The division between different authored relationships, such as a term and its
description or two table cells. It is independent of a visual column boundary.
